# Folder guide

Use only the folders you need. Project / Placement / Type / Images is the recommended structure.

Example paths:
- Fireside / Full Front / Illustrations / image.svg
- Fireside / Full Back / Wordmarks / image.png
- Fireside / Chest / Logos / image.svg
- Fireside / Sleeves / Symbols / image.png
- Fireside / Inside Neck Tags / Labels / label.svg
- Fireside / Anywhere / Textures / texture.png

Placement folders:
- Full Front: full front
- Full Back: full back
- Full: both full front and full back
- Chest: left, right and center chest
- Sleeves: left and right sleeve
- Wrists: left and right wrist
- Shoulder Blades: left and right back shoulder blade
- Back Neck: outside back neck
- Inside Neck Tags: inside neck tag
- Lower Back: lower back
- Front Hems: left and right front hem
- Pocket: hoodie pocket
- Hood Outside: left and right outside hood
- Hood Inside: left and right inside hood
- Anywhere: all placements

Exact placement labels such as Left chest or Right wrist work too. Capitalization and spaces do not matter for recognized names. Asset type folders include Logos, Wordmarks, Illustrations, Labels, Symbols, and Textures. Other subfolders become custom tags. When the first folder is itself a placement or type, it is not treated as a project.

Placement folders assign Preferred within their group and exclude unlisted positions from randomization. Add Allowed positions in Tags & spots to make them eligible in Explore. Files with identical bytes combine preferences across folders unless a position was explicitly excluded in the editor.
