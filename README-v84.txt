ORB Garment Studio v84

INSTALL
Merge the contents into your current v81, v82 or v83 installation, replacing matching files. Keep your existing models, vendor files and asset libraries. Commit and push as usual. The info panel should read ORB Studio 84.

REFERENCE PROPORTIONS
Full-view cameras now use fixed garment proportions calibrated to Sizing proportions.jpg, rather than equalizing torso widths. In the reference back view, the relative silhouette heights are:
Men's hoodie 662, women's hoodie 638, men's tee 594, women's tee 552.
The back-view baseline is shared. Hoodies keep the additional height of their hoods, while tees appear shorter. The men's hoodie also occupies the most vertical space in the opening three-quarter view. Perspective and cloth shape naturally affect the silhouette as you orbit.

BACK ARTWORK
A fixed registration line follows the red guide in the sizing sheet. Every back placement shares one uniform transform. Layer spacing, overlaps, rotations and aspect ratios stay together when switching. The men's tee reference layout remains unchanged. This calibrates the shared canvas; it does not automatically fit each new design, crop artwork at the guide, or independently move lower-back layers.
Existing Fit layout behavior remains available for designs that extend beyond a garment's safe panel. Front, sleeve, hood and inside-neck calibration remain unchanged.

CAMERAS AND EXPORT
Viewing angles and relative zoom are retained when switching. Saved full-view cameras from older builds migrate once to the new framing. Deliberate close-ups remain intact. Click a full-view preset to evaluate the new default framing.
Presentation exports use the same garment proportions with a common envelope that accommodates all four silhouettes.

VALIDATION
Checked actual model projections, reference height ratios, the shared back baseline and artwork guide, full-resolution processing preservation, 414 artwork transform cases, repeated switching, undoable fitting, old-camera migration and export packaging. ZIP CRC and extracted bytes verified.
Live browser/WebGL appearance has not been tested in this environment.
