ORB Garment Studio v91.2 — cameras
Apply to stable v91 or v91.1. Extract into the folder containing index.html,
merge assets, and replace the included files. Commit/push for GitHub Pages.
The v91.1 clipboard feature is included. No hat changes.

Left full sleeve and Right full sleeve appear in Detail for built-in hoodies.
Top-row 8 cycles through these and the existing placement close-ups.
Both sleeve views are also available in mockup export close-ups.

Double-click visible fabric to smoothly focus the camera on that spot.
Drag to orbit around it. Scroll out to return to garment-centered movement.
Empty background and artwork-placement gestures do not trigger focus.

The Info panel describes the new controls.
Validation: JavaScript syntax, sleeve framing math, mesh ray intersections,
placement/background guards, zoom-out recentering, and ZIP integrity.
