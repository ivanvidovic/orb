ORB Garment Studio v91.3 — Organic print patterns

INSTALL
Extract into your existing v91, v91.1 or v91.2 folder (alongside index.html).
Merge assets and replace all included files, then commit/push for GitHub Pages.
Reload after deployment. Includes the clipboard and camera improvements.
No hat changes.

USE
Select a layer, expand Print texture and choose Maze or Branching.
Scale changes pattern size. Thickness changes channel or strand width.
Density changes the generated structure. New variation creates a new arrangement.
Angle, Tone response and Erosion work with these patterns.
Try Scale 70–95 to see larger shapes, or lower values for fine texture.
The current artwork stays visible while a replacement is processed.

Generation runs in the existing artwork worker on supported browsers.
Generated structures are cached in a bounded cache; density and variation
generate a new structure, while other adjustments reuse it.
The seed and density save in .orb files and reproduce the same arrangement
in treated PNG and PSD exports. Original files are preserved.
Open projects using these patterns in v91.3 or newer.

VERIFIED
Maze/Branching in Original, Tint and Solid modes.
Preview, PNG and PSD alpha parity; fitted crop coordinates; repeatable variation;
saved project validation; independent thickness; cached generation.
Existing dots, lines, grain and pixel output matches v91.2.
JavaScript syntax and ZIP integrity checked.
