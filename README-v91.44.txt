ORB Garment Studio v91.44 — artwork and mobile UI update

Merge this complete cumulative patch into the orb(2).zip baseline or the subsequent mobile-tee optimization update, replacing matching files. Include the new mobile-interaction.js module. This package includes render-budget.js and the optimized mobile men's tee GLB. Keep all other existing project files. No GitHub deployment was performed.

Artwork: packed artwork atlases no longer generate mipmaps across unrelated panel tiles. Atlas sampling uses linear base-level filtering with anisotropy 1, plus an explicit outside-tile rejection for artwork and spill sampling. Cleared gutters no longer acquire color from neighboring artwork through the atlas mip chain or repeat edge samples outside a tile. Source-image filtering remains unchanged. This addresses the identified sampling mechanism behind the reported layer-dependent lines. Device-specific visual confirmation remains necessary; minified preview artwork may appear sharper/less smoothed without whole-atlas mipmaps. Print export modules are unchanged.

Mobile UI: removes the men's tee label and the chooser's layout box/spacing/dividers. Nonempty loading/error messages and retry remain available. Blocks browser page pinch/double-tap gestures with mobile-only viewport policy, touch-action rules and cancelable gesture handling. Editable mobile fields use at least 16px text to prevent Safari focus auto-zoom. The existing viewer touch handler remains byte-identical, so pinching the garment preview continues to change the camera. Browser accessibility overrides can still supersede page zoom restrictions.

Preserves the prior mobile men's-tee-only policy, lightweight tee asset, desktop garment cache, rendering budgets, saved-design protections and viewport handling. Glow calculations, geometry, calibration and original artwork files are unchanged.

Verification: reproduced loss of transparent gutters through atlas mip downsampling; checked base-level filtering and both tile guards; tested gesture interception, one-finger scrolling allowance and desktop exclusion; confirmed identical garment pinch handler and glow calculations; verified only the three intended existing files plus the new interaction module differ from the previous update.
